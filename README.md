## How I work

1. State the question and the test before looking at the results
2. Use only information available at the time (walk-forward, no look-ahead)
3. Compare against a benchmark: a simpler model, a random placebo, or a normal distribution
4. Check robustness: sub-periods, out-of-sample data, bootstrap intervals
5. Report the limits (survivorship bias, data gaps) next to the findings

*Some of the code in these projects was written with AI assistance. The research design, testing and decisions are mine.*
